\section{Introduction}
As Large Language Model (LLM) applications evolve from isolated single-turn assistants into cooperative multi-agent workflows---such as Anthropic's Model Context Protocol (MCP) [1], Google's Agent-to-Agent (A2A) JSON-RPC 2.0 orchestrators [2], and multi-agent conversation frameworks such as AutoGen [5]---inter-agent communication overhead has emerged as a primary bottleneck in inference cost, context-window saturation, and key-value (KV) cache memory footprint. In conventional agent topologies, autonomous nodes coordinate state transitions by generating explanatory natural-language prose embedded inside deeply nested JSON schemas. While human-readable, repeated schema keys, conversational filler, and JSON punctuation delimiters consume a disproportionate share of the token budget and scale prefill attention FLOPs quadratically with sequence length.

Attempting to compress inter-agent messages exposes a strict \textbf{Multi-Agent Communication Trilemma}:
\begin{enumerate}
  \item \textbf{Wire Token Efficiency:} Minimizing BPE subword tokens per state transition and amortizing any shared protocol specification across multi-turn sessions.
  \item \textbf{Syntactic, Numeric, and Causal Fidelity:} Guaranteeing 100\% deterministic preservation of structured key-value parameters (e.g., leading-zero string identifiers \texttt{"007"}, embedded delimiters \texttt{"a, b"}, floating-point thresholds \texttt{150.50}), causal transition probabilities $p \in [0,1]$, transition costs $c \in [0, 0.9999]$, and fault-fallback edges (\texttt{!->}).
  \item \textbf{Human Auditability and Cross-Model Portability:} Ensuring that human operators and heterogeneous LLM families (GPT, Claude, Gemini, Qwen, Llama, Gemma) can inspect, verify, and exchange packets over standard text APIs without opaque binary blobs or model-specific hidden-state adapters.
\end{enumerate}

Existing approaches sacrifice at least one vertex of this trilemma. Heuristic perplexity-based prompt pruning such as LLMLingua [4] drops tokens based on language-model perplexity, which risks corrupting JSON syntax delimiters or numeric literals in structured payloads. Conversely, reinforcement-learned (RL) discrete emergent protocols [6, 7] or continuous latent-vector handoffs sacrifice human auditability and cannot traverse commercial text-only REST APIs across heterogeneous model families. Flat key-value templates (\texttt{KEY=VAL}) reduce token count but discard the causal execution graph and fault-recovery semantics.

To address this trilemma with engineering rigor and empirical transparency, we present \textbf{TOAI-elegant-lang (v5.4.3)}, a zero-dependency Python compiler and wire protocol built on an orthogonal Reduced Instruction Set Computer (RISC) instruction architecture and a Tri-Script Rosetta design. Crucially, release \texttt{v5.4.3} incorporates lessons from an intensive multi-AI adversarial audit (conducted across independent ChatGPT and Claude execution sandboxes), replacing idealized assumptions with strictly reproducible, self-contained evaluation tools. Our contributions are fourfold:
\begin{enumerate}
  \item \textbf{8-Bit Orthogonal RISC \& Unified Tri-Script Architecture:} We formalize a three-layer representation aligning \emph{Demotic Wire Script} (compact opcodes \texttt{\S S01..\S X256}), \emph{Sacred Expanded Script} (canonical uppercase identifiers \texttt{\S[A-Z][A-Z0-9\_]*}), and the \emph{Rosetta Audit Layer} (human-readable definitions). We provide an exact BPE subword accounting showing that \texttt{\S}-prefixed opcodes occupy $2\text{--}3$ BPE tokens (\texttt{'\S'} + \texttt{Prefix} + \texttt{Digits}) under \texttt{o200k\_base} and \texttt{cl100k\_base}.
  \item \textbf{Quote-Aware Stateful LL(1) Parser \& Transparent OOV Auditing:} We specify a conflict-free LL(1) Extended Backus-Naur Form (EBNF) grammar paired with a character-by-character quote-aware payload scanner in \texttt{src/codec.py} that losslessly preserves quoted strings (\texttt{"007"}, \texttt{"a, b"}, \texttt{"x]y"}, escaped quotes) and enforces explicit out-of-vocabulary policies (\texttt{on\_oov="error" | "keep" | "nearest"}) with a complete \texttt{oov\_substitutions} audit log.
  \item \textbf{Non-Circular Corpus Alignment Auditor \& Fair Break-Even Benchmark:} To eliminate circular validation between corpus generation and evaluation, we build an independent deterministic auditor (\texttt{src/\allowbreak audit\_corpus\_\allowbreak alignment.py}) governed by domain-specific semantic whitelists and cross-domain bleed blacklists. Validated against a stratified 60-item human audit (\textbf{Cohen's $\kappa = 0.8611$}), the auditor detects and repairs historical scenario-to-wire mismatches (raising alignment from 22.67\% to 100.0\%). We pair this with \texttt{benchmarks/\allowbreak fair\_bench.py}, quantifying token savings and header break-even points across five representations.
  \item \textbf{Statistical Receiver Comprehension Harness \& EUF-CMA Attestation:} We strictly distinguish \emph{syntactic round-trip losslessness} (100.0\%) from \emph{blind receiver semantic comprehension}. We introduce \texttt{benchmarks/\allowbreak eval\_\allowbreak comprehension.py} (implementing Conditions A--E, Shuffle Control, Wilson 95\% CIs, exact McNemar tests, and 4-way option rotation) and report provisional blind evaluation results alongside a formal EUF-CMA security proof for internal-counter HMAC-SHA256 origin attestation.
\end{enumerate}

\section{Related Work and Architectural Positioning}
We position TOAI-elegant-lang relative to four established paradigms in agent communication and prompt compression, restricting all comparisons to verifiable specifications, peer-reviewed literature, and deterministic baselines implemented directly in our repository (Table \ref{tab:arch_comparison}):

\begin{itemize}
  \item \textbf{Classical Agent Communication Languages (FIPA-ACL [3]) and Modern JSON-RPC Orchestrators (MCP [1], A2A [2], AutoGen [5]):} FIPA-ACL standardized performative-based agent messaging (\texttt{inform}, \texttt{request}, \texttt{propose}) using S-expressions or XML. Modern LLM ecosystems such as Anthropic MCP [1] and Google A2A [2] adopt JSON-RPC 2.0 envelopes, while multi-agent frameworks such as AutoGen [5] exchange natural-language turns wrapped in role-tagged JSON dictionaries. While universally portable across text APIs, full JSON-RPC and prose explanations incur high token overhead (349.8 tokens/message in our benchmark), and even stripped-down \emph{Structured Tool JSON} (165.2 tokens) or \emph{Minified Key JSON} (124.2 tokens) repeatedly pay BPE tokenization costs for structural braces, quotes, colons, and field names on every turn.
  \item \textbf{Binary Serialization Formats (Protocol Buffers [8]):} Google's Protocol Buffers and MessagePack achieve compact byte-level encoding over raw TCP sockets. However, LLM text completion APIs cannot ingest raw arbitrary binary octets (\texttt{0x00--0xFF}) directly inside prompt context windows without Base64 ASCII armoring or external tool-call indirection. Base64 encoding inflates byte length by $+33.3\%$ and produces high-entropy alphanumeric strings that fragment into $1\text{--}2$ characters per BPE subword while stripping human readability on the wire.
  \item \textbf{Perplexity-Based Prompt Compression (LLMLingua [4]):} Jiang et al.\ [4] introduced coarse-to-fine prompt compression using a small causal language model to prune low-perplexity tokens before inference. While highly effective for summarizing long natural-language documents or RAG contexts, applying stochastic or perplexity-driven token dropping to structured inter-agent packets risks deleting syntactic delimiters (brackets, quotes, colons) or altering numerical parameters, and requires an auxiliary neural forward pass.
  \item \textbf{Emergent Discrete and Continuous Multi-Agent Communication (Foerster et al.\ [6]; Lazaridou et al.\ [7]):} Deep multi-agent reinforcement learning (MARL) systems learn emergent discrete symbol policies (DIAL/RIAL [6]) or continuous hidden-state projections [7] to coordinate tasks. However, emergent codebooks are tied to the training environment's latent space, lack deterministic human-auditable semantics, and suffer from semantic drift or vocabulary mismatch when transferred across independently trained commercial LLM families.
\end{itemize}

\section{System Architecture, LL(1) Grammar, and Quote-Aware Stateful Codec}

\subsection{Tri-Script Architecture and 8-Bit Orthogonal RISC Lexicon Hierarchy}
TOAI-elegant-lang resolves the tension between wire compactness and human auditability by decoupling the machine-transmitted representation from the human-inspected representation via three deterministic layers (Table \ref{tab:triscript_layers}):
\begin{enumerate}
  \item \textbf{Demotic Wire Script (Compact Machine Layer):} The compact wire format transmitted between agents. It combines a context header (\texttt{@CTX:DOMAIN}), 1-byte logical core opcodes (\texttt{\S S01}--\texttt{\S H32} across 8 semantic categories: \texttt{S} System, \texttt{D} Data, \texttt{G} Governance/Protocol, \texttt{F} Fault/Finance, \texttt{E} Execution, \texttt{A} Audit, \texttt{C} Communication/Gaia, \texttt{L} Logic, plus \texttt{H} Harmony aliases totaling exactly 256 core primitives in \texttt{core\_lexicon.json}), 256 active higher-order macro opcodes (\texttt{\S X01}--\texttt{\S X969} managed via a Least Recently Used [LRU] window in \texttt{macro\_lexicon.json}), bracketed key-value payloads (\texttt{[k:v]}), and causal/fault operators (\texttt{-[p:..., c:...]->}, \texttt{=>}, \texttt{!->}).
  \item \textbf{Sacred Expanded Script (Canonical Symbolic Layer):} A deterministic expansion generated by \texttt{codec.decode(wire)} in which every compact opcode and macro is expanded into its canonical uppercase snake-case identifier matching the strict regular expression \texttt{\^{}\S[A-Z][A-Z0-9\_]*\$} (e.g., expanding \texttt{\S X64} into \texttt{(\S GAIA\_\allowbreak WARMTH\_\allowbreak EXCHANGE > \{ \S SYS\_\allowbreak RESOURCE\_\allowbreak ARBITRAGE\_\allowbreak THROTTLE \} => \S SYS\_\allowbreak LOAD\_\allowbreak FALLBACK)} and \texttt{\S G48} into \texttt{\S PROTO\_\allowbreak HEALTH\_\allowbreak ATTEST}).
  \item \textbf{Rosetta Audit Layer (Human Governance Layer):} Stored in \texttt{rosetta\_layer.json} and \texttt{core\_lexicon.json\allowbreak ["definitions"]}, this layer maps every primitive and macro to a concise English and Japanese specification for compliance auditing and Condition C glossary injection.
\end{enumerate}

\textbf{Honest BPE Subword Tokenization Analysis:} Unlike raw bitstreams, LLM APIs bill and allocate KV-cache memory in discrete BPE subword tokens. Under OpenAI's \texttt{o200k\_base} (GPT-4o) and \texttt{cl100k\_base} (GPT-4 / Claude-compatible) tokenizers, as well as our deterministic fallback estimator \texttt{count\_bpe\_tokens()} in \texttt{src/codec.py}, the non-ASCII section sign \texttt{'\S'} (\texttt{U+00A7}) is tokenized separately from the following ASCII domain letter and two-digit number. Consequently, every canonical \texttt{\S}-prefixed identifier (\texttt{\S S01}, \texttt{\S G48}, \texttt{\S C20}, \texttt{\S X64}, \texttt{\S X354}) consumes \textbf{3 BPE tokens ($2\text{--}3$ tokens: \texttt{'\S'} + \texttt{Prefix} + \texttt{Digits})}, whereas substituting an ASCII prefix (\texttt{@S01} or \texttt{\#S01}) merges the prefix and letter to resolve in 2 BPE tokens. Even at 3 BPE tokens per \texttt{\S}-opcode, collapsing multi-primitive subgraphs into single \texttt{\S X} macros and replacing verbose JSON keys with LL(1) causal arrows reduces whole-packet token count by $41.0\%\text{--}79.1\%$ against lossless JSON baselines (Section 5).

\subsection{Conflict-Free LL(1) EBNF Grammar and Quote-Aware Stateful Payload Parser}
To guarantee deterministic $\mathcal{O}(L)$ parsing without regular-expression backtracking vulnerabilities or silent data corruption, \texttt{toai-elegant-lang v5.4.3} defines a conflict-free LL(1) grammar paired with a stateful character-level payload parser in \texttt{src/codec.py}:

\begin{lstlisting}
(* Canonical LL(1) EBNF Grammar & Lexical Terminals for TOAI-elegant-lang v5.4.3 *)
packet          = [ context_header, "::" ], statement_chain ;
context_header  = "@CTX:", identifier ;
statement_chain = expr_node, { operator, expr_node } ;
expr_node       = ( "(", statement_chain, ")" | "{", statement_chain, "}" | action_node ), [ payload_block ] ;
action_node     = token_id, [ payload_block ], [ guard_block ] ;
token_id        = "§", ( risc_id | macro_id | sacred_name ) ;
payload_block   = "[", kv_pair, { ",", kv_pair }, "]" ;
kv_pair         = identifier, ":", ( quoted_string | float_lit | int_lit | bool_null_id ) ;
guard_block     = "?>", "{", condition_expr, "}" ;
operator        = causal_arrow | seq_arrow | fault_arrow | ">" | "?" ;
causal_arrow    = "-[", [ "p:", float_val, "," ], ( "c:" | "cost:" ), cost_mantissa, "]->" ;
seq_arrow       = "=>" ;   fault_arrow = "!->" ;
sacred_name     = upper_alpha, { upper_alpha | digit | "_" } ;  (* Strict ^§[A-Z][A-Z0-9_]*$ *)
quoted_string   = '"', { ( utf8_char - ( '"' | '\' ) ) | '\"' | '\\' | '\n' | '\t' }, '"' ;
\end{lstlisting}

\textbf{Eliminating Naive Split Bugs via Stateful Quote-Aware Scanning:} During our external adversarial code audit, sandbox testing revealed that naive payload parsers using \texttt{str.split(",")} or unanchored regexes \texttt{r"\textbackslash[(.*?)\textbackslash]"} corrupt structured payloads whenever string values contain commas (\texttt{note:"a, b"}), closing brackets (\texttt{expr:"x]y"}), escaped quotes (\texttt{msg:"say \textbackslash"hi\textbackslash""}), or leading-zero identifiers (\texttt{code:"007"} coerced into integer \texttt{7}). In \texttt{v5.4.2+} and \texttt{v5.4.3}, \texttt{ElegantCodec.\allowbreak \_extract\_\allowbreak outer\_\allowbreak blocks()} and \texttt{ElegantCodec.\allowbreak \_parse\_\allowbreak payload\_\allowbreak block()} implement a deterministic finite-state character scanner tracking \texttt{in\_quotes} and \texttt{escape} flags:
\begin{itemize}
  \item \textbf{Type-Exact Scalar Distinction:} Any value enclosed in double quotes (\texttt{"007"}) is flagged with \texttt{\_\_quoted\_\_ = True} and preserved strictly as a Python \texttt{str} (\texttt{"007"}), whereas unquoted numeric tokens (\texttt{007}, \texttt{42}, \texttt{150.5}) are parsed as \texttt{int} or \texttt{float}.
  \item \textbf{Delimiter Immunity Inside Quotes:} Commas (\texttt{,}), colons (\texttt{:}), brackets (\texttt{[}, \texttt{]}), and \texttt{\S}-prefixed substrings inside quoted string literals are never split or mutated during \texttt{encode()} or \texttt{decode()} (verified by \texttt{test\_07} through \texttt{test\_10} and \texttt{test\_15} in \texttt{tests/test\_codec.py}).
  \item \textbf{Explicit Out-Of-Vocabulary (\texttt{on\_oov}) Policy \& Audit Trail:} Rather than silently mapping unknown symbols to a fallback code such as \texttt{\S G01} or \texttt{\S OMEGA} (which masks failures and inflates apparent compression), \texttt{codec.encode(text, on\_oov=...)} enforces three explicit modes: (i) \texttt{on\_oov="error"} (default), which immediately raises \texttt{UnknownSymbolError}; (ii) \texttt{on\_oov="keep"}, which leaves unregistered symbols untouched on the wire; and (iii) \texttt{on\_oov="nearest"}, which resolves to the closest domain primitive via token-overlap scoring while recording every replacement in \texttt{EncodedWireResult.\allowbreak substitutions} and \texttt{benchmark\_compression()["oov\_substitutions"]} (verified by \texttt{test\_11}--\texttt{test\_14}).
\end{itemize}

\subsection{Non-Circular Independent Corpus Alignment Audit and Human Agreement ($\kappa = 0.8611$)}
During the blind comprehension audit (Section 6), inspecting individual items revealed a critical data quality issue in the historical evolution log (\texttt{corpus/dialogues.jsonl}, $N=1{,}606$ records):
\begin{itemize}
  \item \textbf{Recovery Pattern Leak (e.g., Q3, Q9):} Records labeled with scenario \emph{``Emergency FX hedging under rapid exchange-rate shift''} contained compact wires composed exclusively of fault-recovery primitives (\texttt{\S PROTO\_\allowbreak REPLAY\_\allowbreak GUARD}, \texttt{\S PROTO\_\allowbreak HEALTH\_\allowbreak ATTEST}, \texttt{\S PROTO\_\allowbreak GRACEFUL\_\allowbreak DRAIN}, \texttt{\S SAFE\_\allowbreak FALLBACK\_*}) with zero financial, exchange, or risk primitives.
  \item \textbf{Cross-Domain Bleed (e.g., Q18):} Records labeled \emph{``Syntax parser bugfix task''} contained macro \texttt{\S X64} (\texttt{GAIA\_\allowbreak WARMTH\_\allowbreak ARBITRAGE\_\allowbreak FALLBACK}, expanding to \texttt{\S SYS\_\allowbreak RESOURCE\_\allowbreak ARBITRAGE\_\allowbreak THROTTLE}), causing receiver LLMs to rationally classify the wire as financial arbitrage rather than code debugging.
\end{itemize}

\textbf{Preventing Circular Validation and Data Leakage:} Two methodological pitfalls must be avoided when auditing and repairing a benchmark corpus: (1) relabeling scenarios based on the evaluated LLM's answers constitutes \emph{test-set leakage} and artificially inflates comprehension accuracy; and (2) auditing symbol-to-scenario alignment using the same dictionary \texttt{category} field or keyword lookup table used by the corpus generator creates a \emph{circular reference} that misses the very mismatches produced by the generator.

To guarantee independence, \texttt{src/audit\_\allowbreak corpus\_\allowbreak alignment.py} defines a standalone \textbf{Independent Audit Ontology} (\texttt{INDEPENDENT\_\allowbreak AUDIT\_\allowbreak ONTOLOGY}) that is completely decoupled from \texttt{core\_lexicon.json["category"]} and from all generation specifications. For each of the 7 operational scenario domains (\texttt{FX}, \texttt{CODE\_PARSER}, \texttt{LATENT\_SYNC}, \texttt{TASK\_BUDGET}, \texttt{HYPOTHESIS}, \texttt{GAIA\_HARMONY}, \texttt{RECOVERY}), the auditor expands every macro to its Sacred primitive identifiers and evaluates four deterministic rules:
\begin{enumerate}
  \item \textbf{Plaintext Contamination Check:} Rejects any wire containing raw Japanese characters or natural-language prose outside \texttt{[k:v]} literals as \texttt{MISMATCH (Plaintext Leak)}.
  \item \textbf{Cross-Domain Bleed Blacklist:} Rejects any record whose expanded Sacred symbols match a domain-forbidden token pattern (e.g., \texttt{ARBITRAGE}, \texttt{FX\_}, or \texttt{PORTFOLIO} inside \texttt{CODE\_PARSER}, \texttt{LATENT\_SYNC}, or \texttt{HYPOTHESIS}) as \texttt{MISMATCH (Domain Bleed)}.
  \item \textbf{Recovery Pattern Leak Check:} For any non-\texttt{RECOVERY} scenario, if $>50\%$ of expanded primitives match pure cluster-recovery signatures (\texttt{REPLAY\_GUARD}, \texttt{GRACEFUL\_DRAIN}, \texttt{PARTIAL\_COMMIT}, \texttt{CIRCUIT\_BREAKER}, \texttt{SAFE\_FALLBACK}) and $<2$ domain-specific anchor primitives are present, the record is flagged as \texttt{MISMATCH (Recovery Pattern Leak)}.
  \item \textbf{Required Domain Anchor Whitelist:} Requires at least \texttt{min\_domain\_hits} semantic anchor tokens specific to the scenario domain, otherwise flagging \texttt{MISMATCH (Missing Domain Primitives)}.
\end{enumerate}

\textbf{Human Gold-Standard Validation ($n=60$) and Cohen's $\kappa$:} To validate the reliability of the mechanical auditor itself prior to corpus repair, we extracted a stratified sample of $n=60$ pre-fix corpus records across all 7 domains (\texttt{python src/audit\_corpus\_alignment.py --export-sample 60 --out corpus/human\_audit\_sample.csv}) and compared the mechanical verdict (\texttt{MATCH} vs.\ \texttt{MISMATCH}) against independent human inspection (\texttt{--score-sample corpus/\allowbreak human\_audit\_sample.csv}). The resulting $2\times 2$ confusion matrix recorded \textbf{22 True Matches}, \textbf{34 True Mismatches}, \textbf{2 False Positives}, and \textbf{2 False Negatives}, yielding a raw observed agreement of $p_o = 56/60 = \mathbf{93.33\%}$ over a chance agreement baseline of $p_e = 52.00\%$, and a \textbf{Cohen's Kappa of $\kappa = 0.8611$} ($\text{SE} = 0.0671$, $95\%$ CI: $[0.7296, 0.9926]$, ``almost perfect agreement''). Table \ref{tab:corpus_alignment} reports the pre-fix and post-fix alignment rates across all 1,606 records in \texttt{corpus/dialogues.jsonl}.

\section{Empirical Evaluation I: Fair Multi-Format BPE Benchmark \& Header Amortization}
To avoid inflated compression claims that compare compact wire codes exclusively against verbose natural-language essays, \texttt{benchmarks/fair\_bench.py} evaluates \textbf{TOAI Demotic Wire} against four realistic alternative representations across four representative multi-agent coordination scenarios (\texttt{S1\_FX\_HEDGE}, \texttt{S2\_DIST\_RECOVERY}, \texttt{S3\_TENSOR\_ARBITRAGE}, and \texttt{S4\_PUB\_SEAL\_AUDIT}):
\begin{enumerate}
  \item \textbf{Verbose A2A (Baseline):} Standard natural-language intent prose + semantic specifications + full JSON causal graph.
  \item \textbf{Structured Tool JSON:} Lossless minified JSON (\texttt{separators=(",",":")}) omitting all prose explanations and retaining only structured pipeline steps, parameters, causal transitions \texttt{\{"p":0.99,"c":0.01\}}, and fallback branches.
  \item \textbf{Minified Key JSON:} Aggressive short-key JSON (\texttt{\{"c":"FX\_HEDGE","s":[\{"a":"X64","p":\{...\},"t":[0.99,0.01]\}]\}}) using single-character keys and compact opcode identifiers inside JSON syntax.
  \item \textbf{Simplified Lossy Template:} Flat \texttt{DOMAIN|k1=v1,k2=v2} string template. While requiring only 34.5 tokens, it is \emph{structurally lossy}: it drops intermediate pipeline opcodes, causal transition weights $(p,c)$, and conditional fault-recovery branches (\texttt{!->}, \texttt{?}).
  \item \textbf{TOAI Demotic Wire:} Canonical wire output of \texttt{ElegantCodec().encode(sacred\_verbose, on\_oov="error")}, preserving the full causal AST, all typed parameters, and fault-recovery branches in \textbf{73.2 BPE tokens}.
\end{enumerate}

\textbf{Session Header Amortization (Break-Even Analysis):} In zero-shot cross-model communication where the receiver does not have the codebook pre-loaded, transmitting the active dictionary header costs $H \approx 1{,}000$ BPE tokens at session start. Given per-message token savings $\Delta_{\text{tok}} = T_{\text{baseline}} - T_{\text{wire}}$, the session break-even message count is:
\begin{equation}
  N_{\text{break-even}}^{\text{std}} = \left\lceil \frac{H}{T_{\text{baseline}} - T_{\text{wire}}} \right\rceil, \qquad
  N_{\text{break-even}}^{\text{cache (90\%)}} = \left\lceil \frac{0.10 \cdot H}{T_{\text{baseline}} - T_{\text{wire}}} \right\rceil
  \label{eq:breakeven}
\end{equation}
As shown in Table \ref{tab:fair_bench} and Table \ref{tab:breakeven}, TOAI Demotic Wire achieves net token savings after \textbf{4 messages} against Verbose A2A, \textbf{11 messages} against Structured Tool JSON, and \textbf{20 messages} against Minified Key JSON in uncached sessions---and breaks even within \textbf{1 to 2 messages} when provider prompt caching (90\% discount on cached system prefixes) is enabled.

\section{Empirical Evaluation II: Receiver Blind Comprehension Harness (\texttt{eval\_comprehension.py})}

\subsection{Experimental Hygiene, Five Blind Conditions (A--E), and Statistical Methodology}
A central methodological contribution of \texttt{v5.4.3} is separating \textbf{deterministic codec round-trip accuracy} (\texttt{codec.decode(\allowbreak codec.encode(x)) == x}, which is $100.0\%$ by algebraic construction) from \textbf{zero-shot receiver LLM semantic comprehension} (whether an LLM receiving a wire packet with \texttt{@CTX} and \texttt{[k:v]} stripped can identify the operational scenario among 4 choices at $\texttt{temperature}=0$). Building upon the initial evaluation design by Anthropic Claude, \texttt{benchmarks/\allowbreak eval\_comprehension.py} enforces strict experimental hygiene across five conditions:
\begin{itemize}
  \item \textbf{Condition A (Compact Wire Skeleton Only):} Both \texttt{@CTX:DOMAIN} and all \texttt{[k:v]} payload blocks are stripped, leaving only compact opcodes and causal operators (e.g., \texttt{\S X64 -[p:0.99, c:0.01]-> \S G48 => \S C20}). Tests whether an LLM can infer intent purely from topology and opaque \texttt{\S}-codes ($21.5$ BPE tokens/item).
  \item \textbf{Condition B (Sacred Expanded Names Only):} All macros and primitives are deterministically expanded to their uppercase Sacred identifiers (e.g., \texttt{(\S GAIA\_\allowbreak WARMTH\_\allowbreak EXCHANGE > \{ \S SYS\_\allowbreak RESOURCE\_\allowbreak ARBITRAGE\_\allowbreak THROTTLE \} => \S SYS\_\allowbreak LOAD\_\allowbreak FALLBACK) -[p:0.99, c:0.01]-> \S PROTO\_\allowbreak HEALTH\_\allowbreak ATTEST => \S GENTLE\_\allowbreak RESOURCE\_\allowbreak SHARING}), with \texttt{@CTX} and \texttt{[k:v]} stripped ($48.0$ BPE tokens/item). Directly tests the semantic transparency of Sacred naming.
  \item \textbf{Condition C (Sacred Expanded + Rosetta Glossary):} Condition B augmented with a per-item \texttt{GLOSSARY} block listing the natural-language definitions of all primitives and macros present in the message ($152.0$ BPE tokens/item).
  \item \textbf{Condition D (Shuffle Control -- Negative Control):} Preserves the exact parenthesis, bracket, and causal arrow skeleton of Condition B, but randomly permutes Sacred symbol names across messages using a seeded derangement (\texttt{build\_\allowbreak shuffle\_\allowbreak control\_\allowbreak map()}). If Condition B outperforms Condition D significantly, comprehension is proven to arise from the lexical semantics of the Sacred symbol names rather than superficial structural cues.
  \item \textbf{Condition E (Plaintext Upper Bound):} Replaces the wire with a concise one-sentence natural-language summary of the scenario, establishing the ceiling accuracy of the evaluated LLM on the 4-choice task.
\end{itemize}

\textbf{Protocol Header Isolation (\texttt{--keep-ctx}), 4-Way Option Rotation (\texttt{--rotate-options}), and Paired McNemar Testing:} To prevent context-header leakage, \texttt{eval\_comprehension.py} defaults to \textbf{Skeletal Mode} (\texttt{@CTX} and \texttt{[k:v]} removed). When \texttt{--keep-ctx} is specified (\textbf{Protocol Structure Mode}, retaining \texttt{@CTX:DOMAIN} and masked payload keys \texttt{[pair:*, stop:*]}), outputs are written to separate \texttt{*\_ctx.txt} / \texttt{*\_ctx.json} files and scored independently. To eliminate LLM positional letter bias (e.g., preferring option B or C), \texttt{--rotate-options} replicates each item across all 4 cyclic permutations of options A, B, C, and D ($4N$ trials) and logs the chosen-letter histogram. Proportions are reported with \textbf{Wilson 95\% confidence intervals}:
\begin{equation}
  \text{CI}_{\text{Wilson}}(k, n, z=1.96) = \frac{\hat{p} + \frac{z^2}{2n} \pm z\sqrt{\frac{\hat{p}(1-\hat{p})}{n} + \frac{z^2}{4n^2}}}{1 + \frac{z^2}{n}}, \qquad \hat{p} = \frac{k}{n}
  \label{eq:wilson}
\end{equation}
and paired condition comparisons (\texttt{A vs B}, \texttt{B vs C}, \texttt{B vs D}, \texttt{C vs E}) are evaluated via the \textbf{exact two-sided McNemar test} on discordant pairs $(n_{01}, n_{10})$: $p_{\text{exact}} = \min\!\left(1,\, 2\sum_{i=0}^{\min(n_{01}, n_{10})} \binom{n_{01}+n_{10}}{i} 0.5^{n_{01}+n_{10}}\right)$, alongside the marginal accuracy gain per $+1{,}000$ BPE tokens: $\Delta\text{Acc} / (\Delta\text{Tok}/1000)$.

\section{Threat Model and Unobservable EUF-CMA Proof of Origin Attestation}

\subsection{Unobservable Internal-Counter Attestation Construction (Zero Timestamp Jitter)}
To prevent an active Dolev-Yao adversary $\mathcal{A}$ from injecting forged inter-agent commands, replaying stale packets, or observing rejection-sampling retries under an adaptive Chosen-Message Attack (EUF-CMA), TOAI-elegant-lang embeds a cryptographic origin tag directly into the 4-digit causal cost mantissa $c_n \in [0.0000, 0.9999]$. Let $S_0 \in \{0,1\}^{256}$ be the ephemeral session key established via X25519 ECDH and HKDF-SHA256 (re-keyed every $2^{16}$ turns or upon \texttt{!-> \S F04}, guaranteeing forward secrecy in volatile memory), $H_0 = \text{SHA256}(\texttt{"TOAI\_TELEPATH\_GENESIS\_V541"} \,\|\,\allowbreak \text{SHA256}(\texttt{core\_lexicon.json}) \,\|\,\allowbreak \text{SHA256}(\texttt{macro\_lexicon.json}))$, and $H_{n-1} = \text{SHA256}(H_{n-2} \,\|\, \texttt{0x00} \,\|\, \text{wire}_{n-1})$. For any public turn timestamp $t_n$ (subject to strict monotonicity $t_n > t_{n-1}$ enforced by the receiver), both sender and verifier deterministically compute the canonical 16-bit value $Y_n \in \{0, \dots, 59{,}999\}$ for public confidence mantissa $P_n = \lfloor p_n \times 10^4 \rfloor \in \{0, \dots, 9999\}$ via an \textbf{internal, non-transmitted rejection counter} $r_n \in \{0, 1, 2, \dots\}$ (where $\text{dom}(t_n, r) = t_n$ for $r=0$ and $t_n \,\|\, \text{uint8}(r)$ for $r \ge 1$):
\begin{equation}
  r_n = \min\Bigl\{ r \in \mathbb{N}_0 : \bigl(P_n \oplus \text{trunc}_{16}(\text{HMAC-SHA256}(S_0,\, H_{n-1} \,\|\, \texttt{0x00} \,\|\, \text{dom}(t_n, r)))\bigr) < 60{,}000 \Bigr\}
  \label{eq:internal_counter}
\end{equation}
and set $T_n = \text{trunc}_{16}(\text{HMAC-SHA256}(S_0,\, H_{n-1} \,\|\, \texttt{0x00} \,\|\, \text{dom}(t_n, r_n)))$. Because bitwise XOR $T \mapsto P_n \oplus T$ is a bijection on $\{0, \dots, 65{,}535\}$, each candidate $Y_n^{(r)} = P_n \oplus T_n^{(r)}$ is uniform on $\{0, \dots, 65{,}535\}$ with acceptance probability $60{,}000/65{,}536 = 91.55\%$ (expected internal loop count $\mathbb{E}[r_n + 1] = 1.092$ HMAC calls; for $r_n = 0$, including Table \ref{tab:crypto_vector} where $Y_1 = 9841 \oplus 9247 = 622 < 60{,}000$, it takes 1 call). Given quantized 4-digit integers $P_n = \lfloor p_n \times 10^4 \rfloor \in \{0, \dots, 9999\}$ and $C_n = \lfloor c_n \times 10^4 \rfloor \in \{0, \dots, 9999\}$, verification is defined with explicit operator precedence (16-bit bitwise XOR precedes modulo $10{,}000$ reduction):
\begin{equation}
  \bigl( (P_n \oplus T_n) \bmod 10{,}000 \bigr) = C_n
  \label{eq:mac_verify}
\end{equation}

\subsection{Complete Case Analysis, Unrejected Bias Proof, and Timing Side-Channel Immunity}
\textbf{Theorem 1 (Exact EUF-CMA Forgery Bound Subsuming Direct Tag Guessing and Modular Aliases).} \emph{Under the $(\tau, Q+k, \epsilon_{\text{PRF}})$-PRF security of HMAC-SHA256 and $\epsilon_{\text{coll}}$-collision resistance of SHA-256, for any adaptive EUF-CMA adversary $\mathcal{A}$ (even one that chooses or forces exact timestamps $t_{n+j}^* > t_{n+j-1}^*$), the probability of outputting $k \ge 1$ valid unqueried turns is bounded by:}
\begin{equation}
  P_{\text{forge}}^{\text{internal-rej}}(k) \le \left(\frac{6}{60{,}000}\right)^k + \epsilon_{\text{PRF}} + \epsilon_{\text{coll}} = 10^{-4k} + \epsilon_{\text{PRF}} + \epsilon_{\text{coll}}
  \quad \left(\text{and } P_{\text{forge}}^{\text{unrejected}}(k) \le \left(\frac{7}{65{,}536}\right)^k + \epsilon_{\text{PRF}} + \epsilon_{\text{coll}}\right)
  \label{eq:forgery_bound}
\end{equation}

\emph{Proof.} After eliminating SHA-256 chain collisions ($\text{Game}_1$, loss $\le \epsilon_{\text{coll}}$) and replacing $\text{HMAC-SHA256}(S_0, \cdot)$ with a lazy uniform random function $\mathcal{R}$ ($\text{Game}_2$, loss $\le \epsilon_{\text{PRF}}$), every tuple $(H_{n+j-1}^*, t_{n+j}^*, r)$ for an unqueried monotonic turn $t_{n+j}^* > t_{n+j-1}^*$ is strictly fresh, even when $\mathcal{A}$ chooses $t_{n+j}^*$ and $P_{n+j}^*$ adaptively. We analyze all candidate cost submissions $C_{n+j}^*$ via two exhaustive cases:
\begin{itemize}
  \item \textbf{Case 1 ($C_{n+j}^* \notin \{0, \dots, 9999\}$ -- Deterministic Syntactic Rejection):} By the LL(1) EBNF terminal production \texttt{cost\_mantissa} (Section 3.2), any non-4-digit or out-of-range cost value is deterministically rejected by the lexer prior to MAC evaluation with probability $\Pr[\text{Accept} \mid C_{n+j}^* \notin \{0, \dots, 9999\}] = 0$.
  \item \textbf{Case 2 ($C_{n+j}^* \in \{0, \dots, 9999\}$ -- Exact Congruence Cardinality $|\mathcal{W}(C_{n+j}^*)| = 6$):} Because $T \mapsto P_{n+j}^* \oplus T$ is a bijection on $\{0, \dots, 65{,}535\}$, the first internally accepted value $Y_{n+j} = P_{n+j}^* \oplus T_{n+j} \in \{0, \dots, 59{,}999\}$ is strictly uniform over $\{0, \dots, 59{,}999\}$. For any $C_{n+j}^* \in \{0, \dots, 9999\}$, the winning congruence set $\mathcal{W}(C_{n+j}^*) = \{y \in \{0, \dots, 59{,}999\} : y \equiv C_{n+j}^* \pmod{10{,}000}\} = \{C_{n+j}^* + 10{,}000m : m \in \{0, 1, 2, 3, 4, 5\}\}$ has cardinality $|\mathcal{W}(C_{n+j}^*)| = 6$ (since $C_{n+j}^* + 50{,}000 \le 59{,}999 < 60{,}000 \le C_{n+j}^* + 60{,}000$), subsuming \emph{Direct Tag Guessing} ($m=0$, prob $1/60{,}000$) and \emph{Modular Aliases} ($m \in \{1,\dots,5\}$, prob $5/60{,}000$), yielding $\Pr[\text{Accept}] = 6/60{,}000 = 10^{-4}$ per turn. Without rejection sampling ($Y_{n+j} \in \{0, \dots, 65{,}535\}$), residues $C_{n+j}^* \in \{0, \dots, 5{,}535\}$ admit a 7th alias ($m=6$, since $C_{n+j}^* + 60{,}000 \le 65{,}535$), bounding single-turn forgery by $\max_{C^*} |\mathcal{W}_{\text{unrej}}(C^*)|/65{,}536 = 7/65{,}536 \approx 1.068 \times 10^{-4}$.
  \item \textbf{Timing Unobservability:} Because neither $r_n$ nor rejected candidates are transmitted, and one additional in-cache SHA-256 compression takes $\approx 150\text{ ns}$ on modern CPUs ($\mathbb{E}[r_n] \cdot 150\text{ ns} = 0.092 \times 150\text{ ns} \approx 0.014\text{ }\mu\text{s}$), retry variance is $>6$ orders of magnitude below network/LLM inference jitter ($10^4\text{--}10^5\text{ }\mu\text{s}$), leaking zero observable side-channel information. \qed
\end{itemize}
