\section{Introduction}
As Large Language Model (LLM) applications evolve from isolated single-turn assistants into cooperative multi-agent workflows---such as Anthropic's Model Context Protocol (MCP) [1], Google's Agent-to-Agent (A2A) JSON-RPC 2.0 orchestrators [2], and multi-agent conversation frameworks such as AutoGen [5]---inter-agent communication overhead has emerged as a primary bottleneck in inference cost, context-window saturation, and key-value (KV) cache memory footprint. In conventional agent topologies, autonomous nodes coordinate state transitions by generating explanatory natural-language prose embedded inside deeply nested JSON schemas. While human-readable, repeated schema keys, conversational filler, and JSON punctuation delimiters consume a disproportionate share of the token budget and scale prefill attention FLOPs quadratically with sequence length.

Attempting to compress inter-agent messages exposes a strict \textbf{Multi-Agent Communication Trilemma}:
\begin{enumerate}
  \item \textbf{Wire Token Efficiency:} Minimizing BPE subword tokens per state transition and amortizing any shared protocol specification across multi-turn sessions.
  \item \textbf{Syntactic, Numeric, and Causal Execution Fidelity:} Guaranteeing 100\% deterministic preservation of structured key-value parameters (e.g., leading-zero string identifiers \texttt{"007"}, embedded delimiters \texttt{"a, b"}, floating-point thresholds \texttt{150.50}), causal transition probabilities $p \in [0,1]$, transition costs $c \in [0, 0.9999]$, and fault-fallback edges (\texttt{!->}) required for downstream task execution.
  \item \textbf{Human Auditability and Cross-Model Portability:} Ensuring that human operators and heterogeneous LLM families (GPT, Claude, Gemini, Qwen, Llama, Gemma) can inspect, verify, and exchange packets over standard text APIs without opaque binary blobs or model-specific hidden-state adapters.
\end{enumerate}

Existing approaches sacrifice at least one vertex of this trilemma. Heuristic perplexity-based prompt pruning such as LLMLingua [4] drops tokens based on language-model perplexity, which corrupts JSON syntax delimiters and drops numeric thresholds at aggressive compression ratios ($\rho \le 0.35$). Conversely, reinforcement-learned (RL) discrete emergent protocols [6, 7] or continuous latent-vector handoffs sacrifice human auditability and cannot traverse commercial text-only REST APIs across heterogeneous model families. Flat key-value templates (\texttt{KEY=VAL}) reduce token count but discard the multi-branch causal execution graph and fault-recovery semantics.

To address this trilemma with engineering rigor and empirical transparency, we present \textbf{TOAI-elegant-lang (v5.4.4)}, a zero-dependency Python compiler and wire protocol built on an orthogonal Reduced Instruction Set Computer (RISC) instruction architecture and a Tri-Script Rosetta design. Crucially, release \texttt{v5.4.4} incorporates lessons from an intensive multi-AI adversarial audit and external peer review, replacing small-sample provisional estimates with a strictly disjoint $N=112$ holdout evaluation and formal cryptographic reductions. Our contributions are fourfold:
\begin{enumerate}
  \item \textbf{8-Bit Orthogonal RISC \& Unified Tri-Script Architecture:} We formalize a three-layer representation aligning \emph{Demotic Wire Script} (compact opcodes \texttt{\S S01..\S X256}), \emph{Sacred Expanded Script} (canonical uppercase identifiers \texttt{\S[A-Z][A-Z0-9\_]*}), and the \emph{Rosetta Audit Layer} (human-readable definitions), with exact BPE subword accounting ($2\text{--}3$ BPE tokens per \texttt{\S}-opcode under \texttt{o200k\_base} and \texttt{cl100k\_base}).
  \item \textbf{Quote-Aware Stateful LL(1) Parser \& Downstream Execution Fidelity Benchmark:} We specify a conflict-free LL(1) Extended Backus-Naur Form (EBNF) grammar paired with a character-by-character quote-aware payload scanner in \texttt{src/codec.py} that losslessly preserves quoted strings (\texttt{"007"}, \texttt{"a, b"}, \texttt{"x]y"}) and explicit OOV policies (\texttt{on\_oov="error" | "keep" | "nearest"}). In \texttt{benchmarks/fair\_bench.py}, we quantify the trade-off between token reduction and downstream AST/task execution accuracy against lossless JSON baselines, \texttt{LLMLingua}-style token pruning ($\rho \in \{0.50, 0.35\}$), and lossy templates.
  \item \textbf{Non-Circular Corpus Alignment Auditor ($\kappa = 0.8611$) \& Disjoint Holdout Verification:} We build an independent deterministic auditor (\texttt{src/\allowbreak audit\_corpus\_\allowbreak alignment.py}) governed by domain-specific semantic whitelists and cross-domain bleed blacklists. Validated against a stratified 60-item human audit (\textbf{Cohen's $\kappa = 0.8611$}), the auditor repairs all 1,606 historical records in \texttt{corpus/dialogues.jsonl}. Furthermore, we prove \textbf{0.0\% overlap} (\texttt{--verify-holdout}) between the repaired corpus and the $N=112$ comprehension holdout set (\texttt{corpus/holdout\_comprehension.jsonl}).
  \item \textbf{Large-Scale Holdout Comprehension Evaluation ($N=112$) \& Game-Based EUF-CMA Proof:} Using \texttt{benchmarks/\allowbreak eval\_\allowbreak comprehension.py}, we evaluate $N=112$ holdout items across Conditions A--E, demonstrating statistically significant comprehension gains from Sacred expansion ($p = 1.36 \times 10^{-9}$) and Rosetta definitions ($p = 6.35 \times 10^{-3}$) over Compact Wire and Shuffle Control ($p = 3.59 \times 10^{-17}$), paired with a game-based $(\tau, Q+k)$ EUF-CMA security proof for internal-counter HMAC-SHA256 origin attestation.
\end{enumerate}

\section{Related Work and Architectural Positioning}
We position TOAI-elegant-lang relative to four established paradigms in agent communication and prompt compression, restricting all comparisons to verifiable specifications, peer-reviewed literature, and deterministic baselines implemented directly in our repository (Table \ref{tab:arch_comparison}):

\begin{itemize}
  \item \textbf{Classical Agent Communication Languages (FIPA-ACL [3]) and Modern JSON-RPC Orchestrators (MCP [1], A2A [2], AutoGen [5]):} FIPA-ACL standardized performative-based agent messaging (\texttt{inform}, \texttt{request}, \texttt{propose}) using S-expressions or XML. Modern LLM ecosystems such as Anthropic MCP [1] and Google A2A [2] adopt JSON-RPC 2.0 envelopes, while multi-agent frameworks such as AutoGen [5] exchange natural-language turns wrapped in role-tagged JSON dictionaries. While universally portable across text APIs, full JSON-RPC and prose explanations incur high token overhead (349.8 tokens/message in our benchmark), and even stripped-down \emph{Structured Tool JSON} (165.2 tokens) or \emph{Minified Key JSON} (124.2 tokens) repeatedly pay BPE tokenization costs for structural braces, quotes, colons, and field names on every turn.
  \item \textbf{Binary Serialization Formats (Protocol Buffers [8]):} Google's Protocol Buffers and MessagePack achieve compact byte-level encoding over raw TCP sockets. However, LLM text completion APIs cannot ingest raw arbitrary binary octets (\texttt{0x00--0xFF}) directly inside prompt context windows without Base64 ASCII armoring or external tool-call indirection. Base64 encoding inflates byte length by $+33.3\%$ and produces high-entropy alphanumeric strings that fragment into $1\text{--}2$ characters per BPE subword while stripping human readability on the wire.
  \item \textbf{Perplexity-Based Prompt Compression (LLMLingua [4]):} Jiang et al.\ [4] introduced coarse-to-fine prompt compression using a small causal language model to prune low-perplexity tokens before inference. While effective for summarizing natural-language RAG contexts, applying perplexity-driven token dropping to structured inter-agent packets deletes syntactic delimiters (brackets, quotes, colons) and drops high-entropy numeric thresholds when compressed beyond $50\%$ ($\rho \le 0.35$, Section 5), while requiring an auxiliary neural forward pass.
  \item \textbf{Emergent Discrete and Continuous Multi-Agent Communication (Foerster et al.\ [6]; Lazaridou et al.\ [7]):} Deep multi-agent reinforcement learning (MARL) systems learn emergent discrete symbol policies (DIAL/RIAL [6]) or continuous hidden-state projections [7] to coordinate tasks. However, emergent codebooks are tied to the training environment's latent space, lack deterministic human-auditable semantics, and suffer from semantic drift or vocabulary mismatch when transferred across independently trained commercial LLM families.
\end{itemize}

\section{System Architecture, LL(1) Grammar, and Quote-Aware Stateful Codec}

\subsection{Tri-Script Architecture and 8-Bit Orthogonal RISC Lexicon Hierarchy}
TOAI-elegant-lang resolves the tension between wire compactness and human auditability by decoupling the machine-transmitted representation from the human-inspected representation via three deterministic layers (Table \ref{tab:triscript_layers}):
\begin{enumerate}
  \item \textbf{Demotic Wire Script (Compact Machine Layer):} The compact wire format transmitted between agents. It combines a context header (\texttt{@CTX:DOMAIN}), 1-byte logical core opcodes (\texttt{\S S01}--\texttt{\S H32} across 8 semantic categories: \texttt{S} System, \texttt{D} Data, \texttt{G} Governance/Protocol, \texttt{F} Fault/Finance, \texttt{E} Execution, \texttt{A} Audit, \texttt{C} Communication/Gaia, \texttt{L} Logic, plus \texttt{H} Harmony aliases totaling exactly 256 core primitives in \texttt{core\_lexicon.json}), 256 active higher-order macro opcodes (\texttt{\S X01}--\texttt{\S X969} managed via a Least Recently Used [LRU] window in \texttt{macro\_lexicon.json}), bracketed key-value payloads (\texttt{[k:v]}), and causal/fault operators (\texttt{-[p:..., c:...]->}, \texttt{=>}, \texttt{!->}).
  \item \textbf{Sacred Expanded Script (Canonical Symbolic Layer):} A deterministic expansion generated by \texttt{codec.decode(wire)} in which every compact opcode and macro is expanded into its canonical uppercase snake-case identifier matching the strict regular expression \texttt{\^{}\S[A-Z][A-Z0-9\_]*\$} (e.g., expanding \texttt{\S X64} into \texttt{(\S GAIA\_\allowbreak WARMTH\_\allowbreak EXCHANGE > \{ \S SYS\_\allowbreak RESOURCE\_\allowbreak ARBITRAGE\_\allowbreak THROTTLE \} => \S SYS\_\allowbreak LOAD\_\allowbreak FALLBACK)} and \texttt{\S G48} into \texttt{\S PROTO\_\allowbreak HEALTH\_\allowbreak ATTEST}).
  \item \textbf{Rosetta Audit Layer (Human Governance Layer):} Stored in \texttt{rosetta\_layer.json} and \texttt{core\_lexicon.json\allowbreak ["definitions"]}, this layer maps every primitive and macro to a concise English and Japanese specification for compliance auditing and Condition C glossary injection.
\end{enumerate}

\textbf{Honest BPE Subword Tokenization Analysis:} Unlike raw bitstreams, LLM APIs bill and allocate KV-cache memory in discrete BPE subword tokens. Under OpenAI's \texttt{o200k\_base} (GPT-4o) and \texttt{cl100k\_base} (GPT-4 / Claude-compatible) tokenizers, as well as our deterministic fallback estimator \texttt{count\_bpe\_tokens()} in \texttt{src/codec.py}, the non-ASCII section sign \texttt{'\S'} (\texttt{U+00A7}) is tokenized separately from the following ASCII domain letter and two-digit number. Consequently, every canonical \texttt{\S}-prefixed identifier (\texttt{\S S01}, \texttt{\S G48}, \texttt{\S C20}, \texttt{\S X64}, \texttt{\S X354}) consumes \textbf{3 BPE tokens ($2\text{--}3$ tokens: \texttt{'\S'} + \texttt{Prefix} + \texttt{Digits})}, whereas substituting an ASCII prefix (\texttt{@S01} or \texttt{\#S01}) merges the prefix and letter to resolve in 2 BPE tokens. Even at 3 BPE tokens per \texttt{\S}-opcode, collapsing multi-primitive subgraphs into single \texttt{\S X} macros and replacing verbose JSON keys with LL(1) causal arrows reduces whole-packet token count by $41.0\%\text{--}79.1\%$ against lossless JSON baselines while maintaining $100.0\%$ task execution fidelity (Section 5).

\subsection{Conflict-Free LL(1) EBNF Grammar and Quote-Aware Stateful Payload Parser}
To guarantee deterministic $\mathcal{O}(L)$ parsing without regular-expression backtracking vulnerabilities or silent data corruption, \texttt{toai-elegant-lang v5.4.4} defines a conflict-free LL(1) grammar paired with a stateful character-level payload parser in \texttt{src/codec.py}:

\begin{lstlisting}
(* Canonical LL(1) EBNF Grammar & Lexical Terminals for TOAI-elegant-lang v5.4.4 *)
packet          = [ context_header, "::" ], statement_chain ;
context_header  = "@CTX:", identifier ;
statement_chain = expr_node, { operator, expr_node } ;
expr_node       = ( "(", statement_chain, ")" | "{", statement_chain, "}" | action_node ), [ payload_block ] ;
action_node     = token_id, [ payload_block ], [ guard_block ] ;
token_id        = "§", ( risc_id | macro_id | sacred_name ) ;
payload_block   = "[", kv_pair, { ",", kv_pair }, "]" ;
kv_pair         = identifier, ":", ( quoted_string | float_lit | int_lit | bool_null_id ) ;
guard_block     = "?>", "{", condition_expr, "}" ;
operator        = causal_arrow | seq_arrow | fault_arrow | ">" | "?" ;
causal_arrow    = "-[", [ "p:", float_val, "," ], ( "c:" | "cost:" ), cost_mantissa, "]->" ;
seq_arrow       = "=>" ;   fault_arrow = "!->" ;
sacred_name     = upper_alpha, { upper_alpha | digit | "_" } ;  (* Strict ^§[A-Z][A-Z0-9_]*$ *)
quoted_string   = '"', { ( utf8_char - ( '"' | '\' ) ) | '\"' | '\\' | '\n' | '\t' }, '"' ;
\end{lstlisting}

\textbf{Eliminating Naive Split Bugs via Stateful Quote-Aware Scanning:} During our external adversarial code audit, sandbox testing revealed that naive payload parsers using \texttt{str.split(",")} or unanchored regexes \texttt{r"\textbackslash[(.*?)\textbackslash]"} corrupt structured payloads whenever string values contain commas (\texttt{note:"a, b"}), closing brackets (\texttt{expr:"x]y"}), escaped quotes (\texttt{msg:"say \textbackslash"hi\textbackslash""}), or leading-zero identifiers (\texttt{code:"007"} coerced into integer \texttt{7}). In \texttt{v5.4.2--v5.4.4}, \texttt{ElegantCodec.\allowbreak \_extract\_\allowbreak outer\_\allowbreak blocks()} and \texttt{ElegantCodec.\allowbreak \_parse\_\allowbreak payload\_\allowbreak block()} implement a deterministic finite-state character scanner tracking \texttt{in\_quotes} and \texttt{escape} flags:
\begin{itemize}
  \item \textbf{Type-Exact Scalar Distinction:} Any value enclosed in double quotes (\texttt{"007"}) is flagged with \texttt{\_\_quoted\_\_ = True} and preserved strictly as a Python \texttt{str} (\texttt{"007"}), whereas unquoted numeric tokens (\texttt{007}, \texttt{42}, \texttt{150.5}) are parsed as \texttt{int} or \texttt{float}.
  \item \textbf{Delimiter Immunity Inside Quotes:} Commas (\texttt{,}), colons (\texttt{:}), brackets (\texttt{[}, \texttt{]}), and \texttt{\S}-prefixed substrings inside quoted string literals are never split or mutated during \texttt{encode()} or \texttt{decode()} (verified by \texttt{test\_07} through \texttt{test\_10} and \texttt{test\_15} in \texttt{tests/test\_codec.py}).
  \item \textbf{Explicit Out-Of-Vocabulary (\texttt{on\_oov}) Policy \& Audit Trail:} Rather than silently mapping unknown symbols to a fallback code such as \texttt{\S G01} or \texttt{\S OMEGA}, \texttt{codec.encode(text, on\_oov=...)} enforces three explicit modes: (i) \texttt{on\_oov="error"} (default), which immediately raises \texttt{UnknownSymbolError}; (ii) \texttt{on\_oov="keep"}, which leaves unregistered symbols untouched on the wire; and (iii) \texttt{on\_oov="nearest"}, which resolves to the closest domain primitive via token-overlap scoring while recording every replacement in \texttt{EncodedWireResult.\allowbreak substitutions} and \texttt{benchmark\_compression()["oov\_substitutions"]} (verified by \texttt{test\_11}--\texttt{test\_14}).
\end{itemize}

\subsection{Non-Circular Corpus Alignment ($\kappa = 0.8611$) and Strict Holdout Independence Proof}
During the initial pilot audit, inspecting individual items revealed two systematic defects in the historical evolution log (\texttt{corpus/dialogues.jsonl}, $N=1{,}606$ records): (i) \textbf{Recovery Pattern Leak} (e.g., Q3/Q9 labeled \emph{``Emergency FX hedging''} but containing exclusively fault-recovery primitives \texttt{\S PROTO\_\allowbreak REPLAY\_\allowbreak GUARD}, \texttt{\S PROTO\_\allowbreak HEALTH\_\allowbreak ATTEST}, \texttt{\S PROTO\_\allowbreak GRACEFUL\_\allowbreak DRAIN}), and (ii) \textbf{Cross-Domain Bleed} (e.g., Q18 labeled \emph{``Syntax parser bugfix''} but containing financial arbitrage macro \texttt{\S X64}).

\section{Empirical Evaluation II: Large-Scale Disjoint Holdout Comprehension ($N = 112$)}

\subsection{Experimental Hygiene, Five Blind Conditions (A--E), and Statistical Methodology}
We strictly separate \textbf{deterministic codec round-trip accuracy} (\texttt{codec.decode(\allowbreak codec.encode(x)) == x}, which is $100.0\%$ by construction) from \textbf{zero-shot receiver semantic comprehension} (identifying the correct operational scenario among 4 choices at $\texttt{temperature}=0$ when \texttt{@CTX} and \texttt{[k:v]} payloads are stripped). In \texttt{benchmarks/\allowbreak eval\_comprehension.py}, every item in the disjoint holdout benchmark (\texttt{corpus/holdout\_comprehension.jsonl}, $N = 112 = 16\text{ items/domain} \times 7\text{ domains}$, 4-choice chance $= 25.0\%$) is evaluated across five paired conditions:
\begin{itemize}
  \item \textbf{Condition A (Compact Wire Skeleton Only):} Strips \texttt{@CTX:DOMAIN} and all \texttt{[k:v]} payloads, leaving only compact opcodes and causal operators (\texttt{\S X64 -[p:0.99, c:0.01]-> \S G48 => \S C20}; mean prompt $274.6$ BPE tokens). Tests inference from topology and single-letter domain prefixes (\texttt{S}, \texttt{D}, \texttt{G}, \texttt{F}, \texttt{E}, \texttt{A}, \texttt{C}, \texttt{L}) alone.
  \item \textbf{Condition B (Sacred Expanded Names Only):} Deterministically expands all macros and primitives to uppercase Sacred identifiers (\texttt{\S GAIA\_\allowbreak WARMTH\_\allowbreak EXCHANGE}, \texttt{\S PROTO\_\allowbreak HEALTH\_\allowbreak ATTEST}) with \texttt{@CTX} and \texttt{[k:v]} stripped ($315.3$ BPE tokens, $+40.7$ tok vs.\ Cond A). Directly tests zero-shot lexical transparency of Sacred naming.
  \item \textbf{Condition C (Sacred Expanded + Rosetta Glossary):} Condition B augmented with a per-item \texttt{GLOSSARY} block containing the Rosetta natural-language definitions of all primitives and macros in the wire ($595.3$ BPE tokens).
  \item \textbf{Condition D (Shuffle Control -- Negative Control):} Preserves the exact parenthesis, bracket, and causal arrow skeleton of Condition B, but randomly permutes Sacred symbol names across messages via a seeded derangement (\texttt{build\_\allowbreak shuffle\_\allowbreak control\_\allowbreak map()}, $315.4$ BPE tokens). Proves whether accuracy stems from lexical semantics vs.\ graph length/structure.
  \item \textbf{Condition E (Plaintext Upper Bound):} Concise natural-language summary of the scenario and action chain ($666.1$ BPE tokens), establishing the ceiling accuracy on the 4-choice task.
\end{itemize}

Proportions are reported with \textbf{Wilson 95\% confidence intervals} (Eq.\ \ref{eq:wilson}) [9], and paired condition comparisons on the same $N=112$ items are evaluated via the \textbf{exact two-sided McNemar test} [10] on discordant pairs $(b = n_{10}, c = n_{01})$, continuity-corrected $\chi^2_{\text{cc}} = (|b-c|-1)^2/(b+c)$, discordant Odds Ratio $\text{OR} = c/b$, and \textbf{Cohen's $h$ effect size} $h = 2\arcsin\sqrt{\hat{p}_2} - 2\arcsin\sqrt{\hat{p}_1}$ [11]:
\begin{equation}
  \text{CI}_{\text{Wilson}}(k, n, z=1.96) = \frac{\hat{p} + \frac{z^2}{2n} \pm z\sqrt{\frac{\hat{p}(1-\hat{p})}{n} + \frac{z^2}{4n^2}}}{1 + \frac{z^2}{n}}, \qquad
  p_{\text{McNemar}} = \min\!\left(1,\, 2\sum_{i=0}^{\min(b, c)} \binom{b+c}{i} 0.5^{b+c}\right)
  \label{eq:wilson}
\end{equation}

\subsection{Large-Scale Disjoint Holdout Results ($N = 112$) and Paired McNemar Analysis}
Table \ref{tab:comprehension_results} and Table \ref{tab:mcnemar_results} present the complete empirical results on the $N=112$ disjoint holdout benchmark (\texttt{logs/\allowbreak holdout\_\allowbreak comprehension\_\allowbreak report.json}), alongside the historical $n=23$ pre-fix pilot baseline for full transparency:
\begin{itemize}
  \item \textbf{Highly Significant Gain from Sacred Expansion (Cond A $\rightarrow$ Cond B, $p = 1.36 \times 10^{-9}$):} On bare Compact Wire (Condition A), accuracy is \textbf{44.6\% (50/112)} (95\% CI: $[35.8\%, 53.9\%]$), with Routine Recovery reaching $68.8\%$ ($11/16$) due to structural fault-fallback cues (\texttt{!->}) while Non-Recovery domains average $40.6\%$ ($39/96$). \section{Threat Model and Formal Game-Based EUF-CMA Proof of Origin Attestation}

\subsection{Unobservable Internal-Counter Attestation Construction (Zero Timestamp Jitter)}
To prevent an active Dolev-Yao adversary $\mathcal{A}$ from injecting forged inter-agent commands, replaying stale packets, or observing rejection-sampling retries under an adaptive Chosen-Message Attack (EUF-CMA), TOAI-elegant-lang embeds a cryptographic origin tag directly into the 4-digit causal cost mantissa $c_n \in [0.0000, 0.9999]$. Let $S_0 \in \{0,1\}^{256}$ be the ephemeral session key established via X25519 ECDH and HKDF-SHA256 (re-keyed every $2^{16}$ turns or upon \texttt{!-> \S F04}, guaranteeing forward secrecy in volatile memory), $H_0 = \text{SHA256}(\texttt{"TOAI\_TELEPATH\_GENESIS\_V541"} \,\|\,\allowbreak \text{SHA256}(\texttt{core\_lexicon.json}) \,\|\,\allowbreak \text{SHA256}(\texttt{macro\_lexicon.json}))$, and $H_{n-1} = \text{SHA256}(H_{n-2} \,\|\, \texttt{0x00} \,\|\, \text{wire}_{n-1})$. For any public turn timestamp $t_n$ (subject to strict monotonicity $t_n > t_{n-1}$ enforced by the receiver), both sender and verifier deterministically compute the canonical 16-bit value $Y_n \in \{0, \dots, 59{,}999\}$ for public confidence mantissa $P_n = \lfloor p_n \times 10^4 \rfloor \in \{0, \dots, 9999\}$ via an \textbf{internal, non-transmitted rejection counter} $r_n \in \{0, 1, 2, \dots\}$ (where $\text{dom}(t_n, r) = t_n$ for $r=0$ and $t_n \,\|\, \text{uint8}(r)$ for $r \ge 1$):
\begin{equation}
  r_n = \min\Bigl\{ r \in \mathbb{N}_0 : \bigl(P_n \oplus \text{trunc}_{16}(\text{HMAC-SHA256}(S_0,\, H_{n-1} \,\|\, \texttt{0x00} \,\|\, \text{dom}(t_n, r)))\bigr) < 60{,}000 \Bigr\}
  \label{eq:internal_counter}
\end{equation}
and set $T_n = \text{trunc}_{16}(\text{HMAC-SHA256}(S_0,\, H_{n-1} \,\|\, \texttt{0x00} \,\|\, \text{dom}(t_n, r_n)))$. Because bitwise XOR $T \mapsto P_n \oplus T$ is a bijection on $\{0, \dots, 65{,}535\}$, each candidate $Y_n^{(r)} = P_n \oplus T_n^{(r)}$ is uniform on $\{0, \dots, 65{,}535\}$ with single-draw acceptance probability $60{,}000/65{,}536 = 91.55\%$ (expected internal loop count $\mathbb{E}[r_n + 1] = 65{,}536/60{,}000 = 1.0923$ HMAC evaluations; for $r_n = 0$, including Table \ref{tab:crypto_vector} where $Y_1 = 9841 \oplus 9247 = 622 < 60{,}000$, it requires 1 evaluation). Given quantized 4-digit integers $P_n = \lfloor p_n \times 10^4 \rfloor \in \{0, \dots, 9999\}$ and $C_n = \lfloor c_n \times 10^4 \rfloor \in \{0, \dots, 9999\}$, verification is defined with explicit operator precedence (16-bit bitwise XOR precedes modulo $10{,}000$ reduction):
\begin{equation}
  \bigl( (P_n \oplus T_n) \bmod 10{,}000 \bigr) = C_n
  \label{eq:mac_verify}
\end{equation}

\subsection{Formal Game-Based Security Reduction ($\text{Game}_0 \rightarrow \text{Game}_2$) and Congruence Cardinality Proof}
\textbf{Theorem 1 (Exact EUF-CMA Forgery Bound Subsuming Direct Tag Guessing and Modular Aliases).} \emph{Let $\mathcal{A}(\tau, Q, k)$ be an adaptive EUF-CMA adversary running in time $\tau$ that makes at most $Q$ signing queries to the session MAC oracle $\mathcal{O}_{\text{MAC}}(S_0, \cdot)$ and outputs a $k$-turn unqueried forgery trajectory $\{( \text{wire}_{n+j}^*, t_{n+j}^*, P_{n+j}^*, C_{n+j}^* )\}_{j=1}^k$ satisfying strict timestamp monotonicity $t_{n+1}^* > t_n$ and $t_{n+j}^* > t_{n+j-1}^*$. Under the $(\tau', Q_{\text{PRF}}, \epsilon_{\text{PRF}})$-PRF security of $\text{HMAC-SHA256}$ (where $Q_{\text{PRF}} = \sum_{i=1}^{Q+k}(r_i + 1)$ with $\mathbb{E}[Q_{\text{PRF}}] \le 1.0923(Q+k)$) and the $(\tau', \epsilon_{\text{coll}})$-collision resistance of $\text{SHA-256}$, the probability $\text{Adv}_{\text{TOAI}}^{\text{EUF-CMA}}(\mathcal{A})$ that all $k$ forged turns are accepted is bounded by:}
\begin{equation}
  \text{Adv}_{\text{TOAI}}^{\text{EUF-CMA}}(\mathcal{A}) \le \left(\frac{6}{60{,}000}\right)^k + \epsilon_{\text{PRF}} + \epsilon_{\text{coll}} = 10^{-4k} + \epsilon_{\text{PRF}} + \epsilon_{\text{coll}}
  \quad \left(\text{and } P_{\text{forge}}^{\text{unrejected}}(k) \le \left(\frac{7}{65{,}536}\right)^k + \epsilon_{\text{PRF}} + \epsilon_{\text{coll}}\right)
  \label{eq:forgery_bound}
\end{equation}

\emph{Proof.} We proceed via a sequence of three games $\text{Game}_0 \rightarrow \text{Game}_1 \rightarrow \text{Game}_2$, denoting by $W_i$ the event that $\mathcal{A}$ wins in $\text{Game}_i$:
\begin{itemize}
  \item \textbf{$\text{Game}_0$ (Real EUF-CMA Experiment):} The challenger samples $S_0 \stackrel{\$}{\leftarrow} \{0,1\}^{256}$, initializes $H_0$, answers up to $Q$ adaptive signing queries from $\mathcal{A}$ via Equations (\ref{eq:internal_counter})--(\ref{eq:mac_verify}), and evaluates $\mathcal{A}$'s $k$-turn forgery output. By definition, $\Pr[W_0] = \text{Adv}_{\text{TOAI}}^{\text{EUF-CMA}}(\mathcal{A})$.
  \item \textbf{$\text{Game}_1$ (Abort on SHA-256 Transcript Chain Collision):} Identical to $\text{Game}_0$, except the challenger aborts if two distinct transcript histories $(\text{hist}, \text{hist}')$ ever produce the same chain digest $H = H'$. Any occurrence of this abort yields a direct collision in $\text{SHA-256}$ within time $\tau' \approx \tau + \mathcal{O}(Q+k)$, hence $|\Pr[W_0] - \Pr[W_1]| \le \epsilon_{\text{coll}}$.
  \item \textbf{$\text{Game}_2$ (PRF-to-Uniform-Random-Function Replacement):} We replace $\text{HMAC-SHA256}(S_0, \cdot)$ with a lazily sampled uniform random function $\mathcal{R}: \{0,1\}^* \rightarrow \{0,1\}^{256}$. By standard PRF hybrid reduction over at most $Q_{\text{PRF}}$ oracle evaluations across the $Q$ signing queries and $k$ verification steps, $|\Pr[W_1] - \Pr[W_2]| \le \epsilon_{\text{PRF}}$. In $\text{Game}_2$, because chain digests are collision-free ($\text{Game}_1$) and timestamps satisfy $t_{n+j}^* > t_{n+j-1}^*$, every domain-separated input $X_{n+j}^{(r)} = H_{n+j-1}^* \,\|\, \texttt{0x00} \,\|\, \text{dom}(t_{n+j}^*, r)$ evaluated during the $j$-th forgery verification is strictly fresh (never queried during the $Q$ signing queries or prior turns $1, \dots, j-1$).
  \item \textbf{Exhaustive Residue Class Analysis in $\text{Game}_2$:} For each forged turn $j \in \{1, \dots, k\}$: (1) If $C_{n+j}^* \notin \{0, \dots, 9999\}$, the LL(1) lexical production \texttt{cost\_mantissa} rejects deterministically ($\Pr[\text{Accept}] = 0$). (2) If $C_{n+j}^* \in \{0, \dots, 9999\}$, because $T \mapsto P_{n+j}^* \oplus T$ is a bijection on $\{0, \dots, 65{,}535\}$ and $\text{trunc}_{16}(\mathcal{R}(X_{n+j}^{(r)}))$ is i.i.d.\ uniform on $\{0, \dots, 65{,}535\}$, the first internally accepted draw $Y_{n+j} = P_{n+j}^* \oplus T_{n+j}^{(r_{n+j})}$ conditioned on $Y_{n+j} < 60{,}000$ is distributed uniformly on $\{0, \dots, 59{,}999\}$. The acceptance congruence set $\mathcal{W}(C_{n+j}^*)$ has exact cardinality $6$ for every $C_{n+j}^* \in \{0, \dots, 9999\}$:
  \begin{equation}
    \mathcal{W}(C_{n+j}^*) = \bigl\{ C_{n+j}^* + 10{,}000m : m \in \{0,\dots,5\} \bigr\} \subset \{0,\dots,59{,}999\}
    \;\implies\; \Pr\bigl[Y_{n+j} \in \mathcal{W}(C_{n+j}^*)\bigr] = \frac{6}{60{,}000} = 10^{-4}
    \label{eq:congruence_set}
  \end{equation}
  subsuming \emph{Direct Tag Guessing} ($m=0$, prob $1/60{,}000$) and \emph{Modular Aliases} ($m \in \{1,\dots,5\}$, prob $5/60{,}000$). By independence of fresh $\mathcal{R}$-evaluations across the $k$ turns, $\Pr[W_2] = (6/60{,}000)^k = 10^{-4k}$. Without rejection sampling ($Y_{n+j} \in \{0, \dots, 65{,}535\}$), residues $C_{n+j}^* \in \{0, \dots, 5{,}535\}$ admit a 7th alias ($m=6$, since $C_{n+j}^* + 60{,}000 \le 65{,}535$), yielding $\max_{C^*} |\mathcal{W}_{\text{unrej}}(C^*)|/65{,}536 = 7/65{,}536 \approx 1.068 \times 10^{-4}$. Finally, since $r_n$ is never transmitted and 1 in-cache SHA-256 call takes $\approx 150\text{ ns}$ ($\mathbb{E}[r_n] \cdot 150\text{ ns} \approx 0.014\text{ }\mu\text{s} \ll 10^4\text{ }\mu\text{s}$ network/LLM jitter), timing side-channel leakage is negligible. Summing $\Pr[W_0] \le \Pr[W_2] + \epsilon_{\text{PRF}} + \epsilon_{\text{coll}}$ completes the proof. \qed
\end{itemize}
